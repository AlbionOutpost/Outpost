# Page patterns and regression entrypoints

Read only the row for the affected workflow. The [product workflow](../../../../docs/PRODUCT_UI_WORKFLOWS.md) is the existing product specification; do not invent a missing original specification. Tests listed here are entrypoints, not proof of complete acceptance.

| Workflow        | Required hierarchy and interaction                                                                                                                                                                                                                                  | Existing entrypoints                                                                                                                                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Build Editor    | Searchable item browser → central equipment arrangement → selected-item detail; explicit ability/passive/unlock status; independent alternatives. Mobile views preserve selection. Full equipment-set/consumable coverage cannot be implied by starter slots.       | [editor](../../../../src/components/build-editor.tsx), [equipment workbench](../../../../src/components/equipment-workbench.tsx), [editor e2e](../../../../e2e/build-editor-visual.spec.ts)                                               |
| Composition     | Simultaneous equipment cards for small parties; compact roster for large parties; role/assignment context, member editing drawer/dialog, equipment grids and real PNG download. Check long names, many members, substitutes, reorder and export dimensions.         | [party board](../../../../src/components/party-board.tsx), [editor](../../../../src/components/composition-editor.tsx), [visual e2e](../../../../e2e/composition-visual.spec.ts), [permissions e2e](../../../../e2e/compositions.spec.ts) |
| Market Explorer | Search/identity controls close to dense city comparison rows, independently dated buy/sell observations, chart and item context. Loading filters must not leave prices from another region/item labelled current.                                                   | [market](../../../../src/components/market.tsx), [visual e2e](../../../../e2e/market-visual.spec.ts), [history e2e](../../../../e2e/history.spec.ts)                                                                                      |
| Calculator      | Inputs and assumptions → material quantities/costs → legible result/profit breakdown. Separate cash required, retained returns and effective cost. Put source/manual/unavailable status next to prices. Mobile results remain reachable without losing input state. | [production](../../../../src/components/production-calculator.tsx), [production e2e](../../../../e2e/production.spec.ts), [freshness e2e](../../../../e2e/production-freshness.spec.ts)                                                   |
| Guild workspace | Upcoming events/activity, member overview, shared compositions, announcements and quick actions before administration. Role-dependent controls mirror server permissions; populated, pending and unauthorized states need distinct evidence.                        | [dashboard](../../../../src/components/group-dashboard.tsx), [guild visual e2e](../../../../e2e/guild-visual.spec.ts), [editing e2e](../../../../e2e/group-editing.spec.ts)                                                               |

Judge composition, density, alignment, spacing, typography, source visibility, imagery, button hierarchy and interaction clarity. A theme applied to identical cards across all five pages fails the page-specific requirement.
