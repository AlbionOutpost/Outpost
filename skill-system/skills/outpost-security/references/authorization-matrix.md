For each negative: state expected status/non-disclosure, assert no persisted change and include an allowed control proving the path works. A unit mock of membership is insufficient for a changed transactional authorization boundary; use existing isolated fixture sessions/database tests. Fixtures create owned records and clean up only those records. Never substitute fixtures for real OAuth evidence.

Report missing matrix cells as NOT TESTED. Do not expand a scoped permission review into invasive testing of third parties or a blanket security certification.
