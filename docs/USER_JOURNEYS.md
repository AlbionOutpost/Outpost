## Teams, group builds and published combat

The October29 site refinement connects the actual public Group Builds library to Comps, preserves party positions, optional roles, abilities/alternatives, image controls and independent account copies. Team membership/invitations/events remain the existing protected workflow. Anonymous invitation sign-in returns to explicit confirmation; it does not accept a bearer link automatically.

The loot journey covers manual pool/expenses/weights→exact payout preview→officer save→member read→simulated503 retention/retry→real409 conflict→role downgrade/revocation and departed-participant denial. Account exports require current membership for GROUP compositions and authored ledger metadata; explicit account deletion clears creator attribution while shared history remains. See `e2e/team-loot.spec.ts`, `e2e/account.spec.ts` and [ledger boundaries](engineering/TEAM_LOOT.md).

Global kill/death pages are perspectives on the same source events. Filters apply to the loaded page, and publication delays/unknown gear/quality remain visible. `e2e/combat-feed.spec.ts` uses explicitly mocked source events for outage/retry/region/gear/responsive checks; separate three-region reads verify actual endpoint shape. Neither these fixtures nor browser-auth fixtures establish human Discord consent or in-game execution. Current final counts and screenshots are in [the site review](design-review/site-refinement/README.md).
