# Competitor parity

Feature-by-feature comparison of Outpost against two established Albion Online tool sites, Site A (Albion Online Grind) and Site B (AlbionUtil), used to decide what to build next and what to leave alone.
Competitor columns are based on the archived reconstruction handoffs captured on **27 Oct 2026**; Outpost's column reflects the code and docs on `main` at the time of writing (see [ROADMAP.md](ROADMAP.md), [CALCULATORS.md](CALCULATORS.md), `src/lib/tool-directory.ts`).
Evidence caveat: the handoffs record public pages, shipped client code and worked examples; some competitor features were only visible as disabled previews or client-side code, so a ✔ for them means "shipped" rather than "verified working for a signed-in user". Nothing here copies competitor text, code or art; it summarises behaviour only.

Legend: ✔ has · ◐ partial · ✘ missing · — not applicable to that site.

## Feasible gaps for Outpost (ranked)

Ranked by player value against cost on the Cloudflare Free tier (Workers 100k requests/day, D1, Durable Objects, no paid APIs). Sizes: S = days, M = a week or two, L = several weeks.

1. **Journal economics in crafting.** Fame per craft, journal capacity, full journals per batch and the partial journal are part of every real crafting decision; both competitors have it and Outpost does not. Pure arithmetic over data already archived (journal capacities T2–T8 are known; fame per recipe comes from the game definitions). No new requests. **M.**
2. **Cheapest-path refining.** Buy the previous tier or refine it, including token and enchanted-raw routes down to a stop tier. Site A's standout free-tier-friendly feature; Outpost already has every recipe variant. Runs in the browser from one `/api/economy/prices` call per tier. **M.**
3. **Sitemap, structured data and weapon-family landing pages.** Site A indexes 23k URLs; Outpost ships only `robots.ts`. A `sitemap.ts` over items, builds, comps and guides plus 17 weapon-family routes costs nothing at runtime and is the cheapest growth lever available. **S.**
4. **Tax and setup presets.** Premium and Free presets for sales tax, setup and buy-order fees, kept as labelled user assumptions with 0 still allowed. Removes the most common "why is my profit wrong" moment. **S.**
5. **Enchanting chain upgrade.** Multi-step .0→.3 in one scenario with step and cumulative profit, owned runes/souls/relics reducing purchases, and a per-slot material table. Data is already in `game/upgrades.json`. **S.**
6. **Personal price book on the account.** Saved buy/sell prices per full item ID that pre-fill crafting, refining, transport and shopping. One D1 table, written through the existing scenario-style services; reads stay inside the per-session Durable Object. **M.**
7. **Plan row status and progress.** Mark runs in a production plan as in progress, crafted or hidden, with a progress count and a remaining-only shopping list. Small schema change on saved plans; big usability gain for crafters working through a batch. **S/M.**
8. **Broader opportunity scan.** Lift the 25-item scanner toward a real catalogue scan by batching AODP calls from the browser with progress, partial-batch failure states and a cancel button, the way the competitors' workers do, so the Worker only serves a manifest. Must respect AODP's own fair-use limits and keep "unavailable" rather than zero for missing batches. **L.**
9. **Animals: breeding, products and butchering.** Three calculators over 45 animal definitions already in the owner's archive; formulas are small and testable with hand fixtures. Fills the farming group out to parity with Site A. **M.**
10. **Timers with a focus-cap model and browser notifications.** Add focus regeneration to the cap, laborer/farm cap timers and `Notification` permission handling with one alert per crossing. Entirely client-side plus the existing timers API; no push service. **M.**
11. **Mastery sheets on the account.** Several characters, active-sheet switch, JSON import/export, feeding the focus engine every calculator already uses. Small D1 document per user. **M.**
12. **Nutrition-based station fee.** Usage fee as a percentage of item value × output, matching how stations actually charge. Item values are already served by `/api/items/game`. **S.**
13. **Rich build descriptions.** Sanitised Markdown with inline item and spell references rendered as icons. Needs an allow-list renderer and tests for escaping. **S/M.**
14. **Island manager and rental board.** Personal/guild island records with timers, plus an opt-in public listing with Discord contact only (no payments, no bookings). Owner-scoped rows in D1; the public board is one cached query. **L.**
15. **Volume and liquidity signals.** Weighted 24 h volume from `/api/history` on market rows and scanner sorts, with freshness checked separately from the newest bucket. Bounded by the history budget (300 s cache helps). **M.**

## Deliberate non-goals

- **No website premium or paywall.** Site A gates its planner, flipping, cooking, alchemy, refining and fish tools behind Patreon tiers. Outpost stays free; "in-game Premium" remains only a calculator input.
- **No fabricated or demo numbers presented as live.** Both competitors ship worked examples with fixed timestamps and marketing counters. Outpost shows missing as missing, labels manual values and never displays sample profit tables as current scans.
- **No copying of competitor prose, code, artwork, translations or user content.** Site B's five-language dictionaries, 234-family SEO copy and share-card art, and Site A's guides and build descriptions, are theirs. Outpost's archive of the owner's own site is used as labelled historical content only; the Site B catalogue in the same folder is third-party and is not imported.
- **No unlicensed data as fact.** Nothing becomes "current patch" without a sourced, reviewed import; ao-bin-dumps rights stay an owner decision.
- **No email/password or Twitch sign-in, analytics trackers, ad slots or visitor counters.** Discord-only auth, no third-party scripts, and no engagement metrics the site cannot stand behind.
- **No payment, escrow or booking flows for islands or trades.** If a rental board ever ships it is a contact listing, nothing more.
