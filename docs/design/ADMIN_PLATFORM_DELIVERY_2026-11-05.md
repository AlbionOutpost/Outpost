## Delivered

`/admin` provides stored-account/content statistics, interactive 30-day UTC creation charts, user search/detail, a manual review queue, existing moderator reports and an administrative audit. Current global ADMIN can grant/revoke independent Supporter gifts, revoke regular-user sessions and manage persistent Outpost Discord identity bans. Reasons, strict inputs, current roles, Origin checks, revision conflicts, protected owner/admin identities and atomic audit writes apply server-side. MODERATOR retains reports only. Gifts do not change Stripe; bans do not cancel billing or delete content.

Ban enforcement runs before sign-in, in atomic session creation and on current session reads, including signup races, old cookies and account recreation. Additive private schema 7 and the backend owner-ID binding shipped. Do not roll the data Worker back to schema 6; a web rollback must retain ban enforcement. [Administrative runbook](../ADMINISTRATION.md).

Shared working-page headings, spacing, readable panels and phone Settings navigation were refreshed in Outpost's existing typography/palette. Existing landing, gear editor and personal-comp designs were preserved. The independently reproduced clean guest-draft autosave overwrite is fixed; the original recovery assertion remains and a timing regression was added.
