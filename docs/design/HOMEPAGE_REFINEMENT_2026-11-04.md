## Research and design reasoning

Reviewed the current installed Next CSS guide and project frontend, visual QA, release, Impeccable polish/craft-floor and motion guidance. Impeccable launcher execution was denied by the mounted filesystem; existing PRODUCT.md, DESIGN.md and project context were read directly. Browser MCP returned an approval-policy rejection; permitted sandboxed Playwright and native Firefox were used and labelled as fallback.

[Chrome motion guidance](https://developer.chrome.com/docs/modern-web-guidance/guides/ui-behaviors/motion) supports animating compositor-friendly transform/opacity properties; [Material duration/easing guidance](https://m1.material.io/motion/duration-easing.html) supports short responsive transitions with duration suited to distance. [MDN reduced-motion guidance](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion) informs the static alternative. These principles were adapted to Outpost's existing artwork and browser defect, then checked through intermediate states and reversal rather than accepted from source alone.
