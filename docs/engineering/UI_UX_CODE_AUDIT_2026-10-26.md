# UI/UX and engineering audit — 26 October 2026

Historical audit-only snapshot. The subsequent user-authorized [implementation and before/after browser review](../design-review/refinement/README.md) records fixes and retests; findings below describe the original audit state.

This is the prioritized improvement plan requested after the skill review. **No application fixes were made after the audit-only request.** A SHA-256 comparison of 219 runtime source/schema/assets/data/configuration files confirms the application stayed unchanged. Skill files, AGENTS guidance, vendor tooling exclusions and reports are the setup changes. Earlier authorized milestone changes remain in the workspace and are not presented as changes made by this audit.

The visual identity is coherent and appropriate for an Albion companion: charcoal/copper surfaces, recognizable equipment, Barlow display headings, Inter controls and Geist numeric values. Preserve it. The best next work is targeted accessibility, narrow-screen robustness, font delivery, verification coverage and workflow clarity; a wholesale redesign is not justified.

## Actual audit scope and commands

The six [reviewed skills](DEVELOPMENT_SKILLS.md) were explicitly read/applied, composed with the existing Outpost skills. New automatic discovery remains blocked by the read-only skill destination. Native Browser plugin was absent; actual Playwright MCP was denied by approval policy and DevTools MCP lacked its configured Chrome. Evidence uses the installed local-library fallback, Chromium CDP and Lighthouse.

Rendered production inspection covered **29 routes × six viewports = 174 configurations**: 320×844, 375×844, 390×844, 768×1024, 1440×900 and 1920×1080. Routes: home, market, editor, build detail, builds, composition editor/detail/directory, crafting, refining, enchanting, dashboard, items/detail, guides, guild/directory/creation, favorites, gold, trade, transport, timers, tools, settings, profile, moderation, unavailable invitation and legal. Populated equipment, groups, rosters and sessions are isolated owned fixtures; market/history records are explicitly synthetic. Screenshots wait for the expected heading, fonts and visible images. No console/page error or failed request was recorded in that capture exercise. **173 configurations fit; item detail at 320px fails.**

Five contact sheets and representative full-size desktop/mobile images were opened, including item detail, catalog, composition gallery, editor and the existing Market/composition references. Follow-up Market/item-detail captures after the final phase rebuild reproduced the item overflow. Visual review identifies material issues; it is not owner acceptance or a numerical similarity score.

Unrestricted axe ran on eight populated routes at 1440 and 390 (**16 state/viewport checks**). Raw evidence includes an injected QA-label `region` warning; the reviewed summary removes only that known test artifact. The serious label/name findings and desktop landmark finding remain. Incomplete color-contrast/ARIA checks are retained for manual review. The absence of further automated violations is not a full accessibility pass.

Impeccable's source detector completed with exit **2**, meaning findings, and returned four `side-tab` warnings. Code/rendered review traced these to the alert border, active workspace navigation, guide-section accents and guild banner. The alert/active-state rules communicate function; removing them blindly would weaken the interface. The guide/banner accents are optional visual-polish questions under the existing brand, not proven P1 defects. No detector rule was disabled to manufacture a clean report.

The final `npm run qa:phase` on Node 22.22.2/local PostgreSQL/Redis passed all ten automated gates: **143 unit tests, 59 browser tests, 15 disposable database checks and nine regional endpoint checks**. Targeted watchlist ownership/cache/cap, calculator expected values, source validation, saved scenarios and responsive interactions remain covered. Source-pattern scan: 577 files, zero scoped findings; configured-secret bundle scan: 47 files, zero matches. `scripts/test-docs-validation.py` has 17 passing checks. Generated QA documents preserve these automated results independently of the newly failed visual/accessibility scopes.

Key commands: `npm run qa:phase`; `npm run data:audit`; `python3 scripts/install-project-skills.py --check`; pinned Impeccable `context` and `detect src --json`; existing local Playwright capture workflow; `scripts/qa-market-performance.mjs skills-audit ...`; source/bundle secret scans and report validation.
