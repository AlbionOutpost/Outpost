Only GitHub Actions with the explicit reporting policy may record that as **BLOCKED**, with a visible job warning/summary; it never counts as a public application or OAuth PASS. All ordinary403s, resource-limit503s and application failures still fail. Outside that explicit CI context, blocked checks remain nonzero. The strict public smoke/auth commands are unchanged.
