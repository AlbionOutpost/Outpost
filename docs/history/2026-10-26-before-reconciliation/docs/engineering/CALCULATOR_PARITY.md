## Formula verification boundary

`DATA_SOURCES.md` documents original arithmetic and source leads. Profit = gross revenue − fees − effective costs; eligible retained returns reduce economic cost, not upfront cash. Focus assumptions and tax percentages are user inputs. Missing source timestamps warn; missing source prices never become free inputs. Current patch/version-specific source validation remains unresolved where official/wiki requests return403. Do not call these inputs current verified game defaults.

Priority: preserve calculation/source correctness, expand permitted data, test each major production mode independently, then build the missing mechanics. Do not add decorative calculator routes that imply unsupported models work.
