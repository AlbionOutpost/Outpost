## Draft and failure recovery

Private account drafts are never automatically copied into localStorage or sessionStorage. Dirty account edits register beforeunload protection and confirmation for ordinary same-tab document links, including the Builds link, header navigation and Add saved build to comp. Confirm cancellation leaves the draft intact. Shared sign-out asks before discarding dirty edits and clears recovery after explicit confirmation.

An additional real browser-history review reproduced silent loss: browser Back unmounted a dirty account editor with no dialog, and Forward restored the saved title. The same document marker survived, proving that beforeunload could not protect this SPA journey. The original failure remains in `.qa/builds-reference/editor/history-check.json` and `history-forward.png`.

The follow-up implementation retains up to eight account drafts in document memory for30minutes, bounded to262,144 JSON characters each, and explicitly restores them after navigation. Server-authorized owner identity and build/new-source scope isolate entries; owner changes/logout invalidate outstanding writer leases. No Next history interception or private browser persistence is introduced. Restoration retains the original base revision, so a draft recovered against a newer server revision receives an explicit notice and still encounters the existing409 protection. Oversized drafts receive an actionable recovery warning without truncation or restoration of an older partial snapshot. Successful save clears the matching draft. Full reload/sign-out and bounded expiry remain explicit recovery limits; Save/JSON export are permanent recovery paths. Four unit cases and expanded existing browser recovery assertions are implemented; their exact post-change execution is pending the parent's coordinated phase.

Recovery previously deferred readiness to an animation frame, while a dirty passive writer could skip early edits and had no account unmount flush. The follow-up fix disables account form controls until recovery finishes and records committed account drafts in a layout effect, including a memory-only unmount flush. Successful Save clears that snapshot before navigation; logout-invalidated leases cannot repopulate it. The immediate navigation assertion is unchanged. Exact rebuilt-production execution remains pending the parent; there is no added sleep or relaxed expected title.
