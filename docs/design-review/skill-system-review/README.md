## Corrected and retested

The collapsed workspace sidebar hid the saved-workspace text, leaving an icon-only link without an accessible name. Initial phase:132 unit tests passed,54 browser tests passed and 3 accessibility audits failed on `.workspace-saved`. Added `aria-label` and tooltip in [workspace navigation](../../../src/components/workspace-navigation.tsx). Final phase:132 unit/57 browser/15 disposable DB checks and all 10 commands PASS. The initial logs are retained under `.qa/skill-system/initial-phase`; no visual redesign or pixel change is claimed from this semantic fix.

## Viewports, states and measurements

Inspected actual populated captures at 1440×900,1920×1080,768×1024,390×844,375×844 and 320×844, plus 327×576 matching the supplied crop dimensions. All measured document widths equal the viewport. Exact 327px comparison is particularly useful for hierarchy; it does not make the two applications' data/workflows equivalent. [Side-by-side comparison](reference-comparison.png) retains original reference dimensions without stretching.

Controlled fixtures contain eight T4_BAG city observations, one unavailable sell side, deliberately old separate timestamps and three historical points. The capture label states that prices are fixtures, never live. Also inspected settled initial, pending request, empty response,503 error and all-prices-unavailable states at 390px. The first streamed initial screenshot was rejected and recaptured after visible-content assertions. Initial icons were still pending in that supplementary capture; loaded populated captures, not that image, support icon observations. City filtering, search dropdown and Escape succeeded; no pageerror was recorded in the exercise. This is sampled UX evidence, not full accessibility conformance.

Computed heading/control fonts match Barlow Condensed and Inter in the inspected capture; numeric styling comes from the existing Geist Mono system and passing reference-UI regressions. No broad typography redesign was performed.

One Lighthouse 13.5.0 mobile simulation on the anonymous initial production route: Performance 96, Accessibility 100, LCP 2.818s, CLS 0, TBT 24.5ms. Three separate warm unthrottled loopback fixture interactions reached eight rows in 59.7–63.8ms (median 61.4ms, automation wall time). These proxies do not measure field INP or realistic source/network latency. The synthetic runs and Lighthouse initial-route state are different protocols and are not pooled. No performance optimization or measured speedup is claimed.
