# Authorization matrix

For each resource you change, fill actor × action. Actors: anonymous · owner/author · unrelated signed-in user · Team OWNER / ADMIN / OFFICER / MEMBER · revoked or demoted member · site ADMIN/MODERATOR. Actions: read · list/search · export · duplicate · create · update · delete · role/visibility change.

| Resource                                     | Must hold                                                                                                                                                                                                                                                                                              | Code                                                                             | Specs                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **Build**                                    | Only the owner mutates; visibility public / unlisted / private / hidden respected on direct URL, discovery and search; old revisions follow current visibility; duplicate creates an independent copy; restore makes a new revision; author/ID can't be forged; expected-version conflicts rejected    | `src/lib/builds/service.ts`, `src/app/api/builds/**`                             | `builds`, `verified-builds`, `build-sharing`, `qa-security`         |
| **Comp**                                     | Public / private / Team visibility on read and list; members read, officers+ edit Team comps; demotion and revocation take effect immediately; attached builds must be readable by the viewer; duplicate detaches from source; revisions and export respect access                                     | `src/lib/compositions/service.ts`, `repository.ts`                               | `compositions`, `composition-recovery`, `groups`                    |
| **Team**                                     | Roles from current membership; `canEditShared` = owner/admin/officer, `canManageMembers` = owner/admin (invite, remove), role changes owner only; invitations hashed, expiring, revocable, single use; ownership transfer is transactional; private Teams 404 to outsiders; no cross-Team destinations | `src/lib/groups/permissions.ts`, `service.ts`, `loot-service.ts`                 | `groups`, `group-editing`, `group-builds`, `team-loot`              |
| **Community**                                | Favorites, votes, comments, reports need a session; Turnstile in production; hidden content stays hidden from lists; moderation requires current ADMIN/MODERATOR                                                                                                                                       | `src/lib/community/*`                                                            | `community`, `qa-security`                                          |
| **Account / scenarios / timers / watchlist** | Owner only for read, list, write, delete; export excludes OAuth/session tokens; deletion blocked while owning a Team; `no-store` responses; failed saves keep the draft                                                                                                                                | `src/app/settings/actions.ts`, `api/scenarios`, `api/timers`, `api/market-watch` | `account`, `settings-recovery`, `trade-scenarios`, `personal-tools` |
| **Shared caches**                            | Public market cache keyed by full identity with bounded TTL; nothing private ever enters a shared cache; revoke a role then re-request                                                                                                                                                                 | `src/lib/redis.ts`, `cloudflare/database/redis-web.ts`, `inflight-cache.ts`      | `cache-expiry`, `redis-recovery` (unit), `qa-security`              |

Every denied case asserts the expected status, a non-disclosing body and **no persisted change**, alongside an allowed control proving the path works. Mark any cell you didn't test as untested in the report.
